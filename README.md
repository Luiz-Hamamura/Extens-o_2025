# 📚 Projeto de Extensão — 2025

Projeto desenvolvido como parte das atividades de **Extensão Universitária**, realizado durante a graduação em **Sistemas de Informação**.

## 📖 Sobre o projeto

Este repositório contém os arquivos e códigos desenvolvidos durante o projeto de extensão realizado em 2025.

O projeto foi desenvolvido utilizando **Java** e ferramentas do ecossistema Java, com estrutura baseada em **Maven**.

## 🛠️ Tecnologias utilizadas

* ☕ Java
* 📦 Maven
* 💻 NetBeans
* 🌐 Java Web

## 🎯 Objetivos

O projeto teve como objetivo aplicar, na prática, conhecimentos adquiridos durante a graduação, relacionando o desenvolvimento de software com atividades de extensão universitária.

Entre os conhecimentos trabalhados estão:

* Desenvolvimento em Java
* Organização de projetos Maven
* Desenvolvimento de aplicações
* Estrutura de projetos Java Web
* Utilização de IDE para desenvolvimento
* Aplicação prática de conhecimentos acadêmicos
